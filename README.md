# ExitBug 🐞

A stealth-adventure game where you navigate through grid-based levels, uncover tiles, and escape through the portal.

> **[Play the Live Demo](https://shiny-starburst-97ef82.netlify.app/)**

## Features
*   **Stealth Gameplay**: Avoid detection while exploring.
*   **Progression**: Earn XP and upgrade skills.
*   **Responsive Design**: Works on desktop and mobile.

## Development

Run the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Tech Stack
*   React
*   Vite
*   Tailwind CSS
*   Netlify (Hosting)
